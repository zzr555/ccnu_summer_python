# Python 命令行小Demo快速开发 Skill
## 一、目标
帮助Python新手快速产出一个可运行、带异常处理的命令行小工具，减少基础语法报错，保证代码可直接运行交付。

## 二、适用场景
- 课程作业需要快速完成Python小Demo
- 开发简单的命令行计算、统计、查询类工具
- 零基础完成单文件Python小项目

## 三、核心执行流程
### 第1步：先定边界再动手
写代码前明确3件事：
1. 输入：用户需要输入什么内容、格式要求
2. 输出：最终要展示什么结果、排版形式
3. 不做什么：比如不做图形界面、不连接数据库、不引入第三方库

### 第2步：按职责拆分函数
至少拆分为3个独立函数：
- **输入获取函数**：负责接收用户输入、做基础格式校验
- **逻辑处理函数**：负责核心计算/统计逻辑，不掺杂输入输出
- **结果输出函数**：负责格式化展示最终结果

### 第3步：补齐三类异常处理
必须覆盖所有新手高频踩坑场景：
- 非法输入：用户输入文字、符号等非预期内容
- 空数据：用户未输入有效内容直接结束
- 边界值：数值超出合理范围（如负数、满分以上的分数）

### 第4步：单步验证
每写完一个函数单独测试：
1. 传入正常参数，确认输出结果正确
2. 传入异常参数，确认程序不会直接崩溃
3. 传入边界值，确认逻辑符合预期
